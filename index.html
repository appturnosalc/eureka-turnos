📘 Manual Eureka

1. Acceso y login

La aplicación se abre con la pantalla de acceso. Debes introducir usuario y contraseña para entrar. Si el usuario es de tipo trabajador y es la primera vez que accede, el sistema le pedirá cambiar la contraseña inicial. La nueva contraseña debe ser un PIN de 4 dígitos, y no puede coincidir con el usuario, el número de empleado, el ID del trabajador ni con la contraseña actual.

Los accesos por defecto son:

  • Administrador: admin / admin123
  • Gestor: gestor / gestor123

Si el usuario falla la contraseña varias veces, la cuenta puede quedar bloqueada y necesitar un desbloqueo por parte del gestor o administrador.

2. Pestaña Turnos

Es la vista principal del cuadrante. Aquí se visualiza la planificación semanal del personal. Cada fila representa a un trabajador y cada columna representa un día o franja del calendario. Las celdas contienen los turnos asignados.

  • Cómo navegar: hay botones para retroceder semana, avanzar semana y volver a la semana actual.
  • Cómo cambiar un turno: se selecciona la celda correcta, se modifica el turno y se confirma el cambio.
  • Cómo copiar un turno: se reutiliza un patrón de horario sobre otra celda o rango, según la funcionalidad disponible.
  • Cómo deshacer: existe la opción de deshacer la última acción para corregir errores.
  • Colores: los colores ayudan a diferenciar funciones, estados y distribución del personal.
  • Filtros: permiten ver solo grupos de trabajadores por función.

3. Pestaña Funciones

La pestaña funciones organiza la estructura operativa de la aplicación. Sirve para clasificar cada empleado por función y para controlar la cobertura por tipo de trabajo.

  • Se asigna la función al trabajador desde RRHH.
  • Las funciones se usan para segmentar la planificación.
  • Se usan también en los filtros y en la exportación de datos.
  • Hay límites funcionales para asegurar que cada franja tenga la cobertura necesaria.

4. Pestaña Cobertura

La cobertura permite ver si el personal disponible es suficiente para cubrir las necesidades del día. Si faltan personas en una franja, aparece la necesidad de cobertura. Se corrige desde la planificación y ajustando turnos o funciones.

  • Se observa la necesidad real de personal por franja.
  • Sirve para detectar faltas o sobrecargas.
  • Se utiliza para equilibrar la asignación del personal.

5. Pestaña Vacaciones y Libranzas

Esta vista se usa para gestionar las ausencias anuales de vacaciones y las libranzas del personal. Se selecciona el año o el mes y se controla qué calendario está publicado o no.

  • Publicar Año: deja el año visible y operativo para la planificación interna.
  • Despublicar Año: elimina la visibilidad del año publicado.
  • Se usa para controlar la disponibilidad real de vacaciones y libranzas.
  • La publicación afecta a la visibilidad del calendario para uso interno.

6. Pestaña Horas

La pestaña horas gestiona la carga horaria de cada trabajador. Aquí se entran y revisan los valores de horas anuales, semanales o diarias, según el tipo de contrato o planificación.

  • Se elige el tipo de horas.
  • Se completan los valores de horas anuales, semanales o diarias.
  • Esto ayuda a controlar la carga real y la planificación operativa.

7. Pestaña RRHH fichas

RRHH es la base de datos del personal. Aquí se dan de alta, modifican y eliminan empleados, así como sus condiciones de trabajo, color, contrato, teléfono, email, funciones y restricciones.

  • Alta Nuevo Empleado: abre el formulario para crear una ficha completa.
  • Número Empleado: identificador interno.
  • Usuario: nombre de acceso del empleado.
  • Contraseña: se puede dejar temporal o actual. Si es un trabajador con acceso inicial, debe cambiarla al entrar por primera vez.
  • Nombre y Apellidos: datos obligatorios.
  • Alias: nombre corto usado en la app.
  • Adaptación / Restricciones: notas que afectan al día a día.
  • Función: categoría laboral.
  • Contrato: tipo de contrato del empleado.
  • Color: asigna visualmente al trabajador.
  • Horas: se rellenan según el tipo de jornada.
  • Actividad: permite añadir periodos de alta o baja, o tramos de actividad.

La información del trabajador se actualiza en tiempo real en todas las vistas de la aplicación.

8. Pestaña Listados y Envíos

Es la parte de salida de la aplicación. Aquí se prepara y exporta la información del planning, las publicaciones y las fichas de jornada.

  • Envío de planning: se selecciona una fecha y se exporta el planning en Excel.
  • Publicar Turnos: se elige desde, hasta y filtro por función. Luego se publica el rango.
  • Deshacer Publicación: revierte la publicación de un rango.
  • Publicar Vacaciones y Libranzas: publica el año seleccionado para la visibilidad del calendario.
  • Jornada / Variables: se usa para exportar fichas por trabajador y mes.

9. Pestaña Documentación

La documentación sirve para enviar archivos o avisos al trabajador. Si hay documentos pendientes de lectura, el sistema puede bloquear partes de la aplicación hasta que el trabajador confirme la lectura.

  • Se cargan documentos o avisos.
  • El trabajador debe marcarlos como leídos.
  • Si siguen pendientes, ciertas pestañas quedan deshabilitadas.

10. Consejos de uso

  • Actualiza la ficha de cada empleado siempre que cambie su función, contrato o datos de contacto.
  • Mantén una lógica uniforme de colores para que el cuadrante sea fácil de entender.
  • Valida fechas y rangos antes de publicar.
  • Usa los filtros para evitar errores al planificar grandes cargas de personal.
  • Haz copias de seguridad periódicas para evitar pérdida de información.
  • Si un trabajador es nuevo, asegúrate de cambiar su PIN inicial en el primer acceso.
